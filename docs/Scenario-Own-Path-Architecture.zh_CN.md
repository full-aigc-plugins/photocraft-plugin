# 场景技能自身安装目录

首用示例定位宿主实际加载的 SKILL.md 所在目录。用户级、项目级、插件内的例示目录必须命名当前技能自身；单独安装场景技能无需其兄弟 CLI 技能。

```mermaid
flowchart LR
 H[宿主加载场景 SKILL.md] --> D[当前技能绝对目录]
 D --> Q[带引号的 SKILL_DIR 脚本入口]
 Q --> L[核验固定运行时锁]
 L --> C[公开原生命令]
```

四域共六个示例此前错误命名通用 CLI 兄弟技能。本修正仅改变这些目录示例，并将两项套件版本记录对齐既有运行时锁；不改变原生二进制或运行时制品。既有路径检查现在拒绝兄弟目录例示；套件检查要求每个锁与运行时元数据一致。

验证复制全部54领域技能到三个含空格布局，474次文档帮助入口调用通过，不触发安装副作用。源回归通过，条件原生测试跳过单列。[候选证据](evidence/scenario-own-path-candidate-20261008.json)。固定标签插件安装与实际空缓存运行时使用仍是独立发行门禁；本证据不替代创作任务或完整V1。
