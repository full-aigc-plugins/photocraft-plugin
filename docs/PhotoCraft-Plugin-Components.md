# PhotoCraft plugin component boundary

The root `plugin.json` provides the portable Agent Plugins 1.0.0 identity. The 14 immediate skill directories contain 13 pinned source snapshots and one plugin-local task-control skill. Claude Code commands and the session hook live under `com.anthropic.claude-code/`, with explicit paths in `.claude-plugin/plugin.json`. Commands pass input to their matching skill. The hook only reminds Claude to reuse the owned native instance when a session starts or resumes; it does not install, start or close the native application. Other clients discover skills from the portable fixed location without this extension.

Skills call the pinned PhotoCraft CLI through their bundled scripts. Continuous work reuses its owned session, and an uncertain result is reconciled against the original request. The plugin-local Harness remains an explicit advanced entry governed by the existing OpenSpec contract; ordinary domain commands do not invoke it by default. `src/` provides the existing task controller and `scripts/` contains development validation and release tools. Neither is a new portable Agent Plugins 1.0.0 component.

`claude plugin validate . --strict` validates the Claude manifest. This local validator reports empty `contents`, so its exit code does not prove that Claude discovered the 14 commands or routed a request. Package tests check every command target, the single SessionStart hook, and the absence of native process management in that hook. Fixed installation, model selection and actual native delivery remain separate PC-RL-001 gates.
