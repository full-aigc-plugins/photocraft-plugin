# PhotoCraft 桌面聚合监督

自有桌面包装层把聚合剩余timeout传入实际MCP stdio会话，并在整批结束后恢复原值；不能按子请求重置父批次截止时间。规范实现位于 `skills/photocraft-use/scripts/desktop_session.py`，独立技能由同一源同步。

候选使用锁定的签名PhotoCraft桌面0.2.0及维护版CLI craft.5。12个真实GUI案例覆盖健康结果引用及检查点／保存／重开、合法通知、显式continue下原生失败、七类异常回复、累计响应预算和整批截止时间。只读实时检查仅为测试观察，不是自动恢复或重放；只关闭测试拥有的GUI和CLI。原工程与批次前检查点保持不变并可重开，失败后没有后续保存。

真实stdio延迟回复测试重现包装层缺陷；同一真实GUI截止时间案例在公开dev.54源上也失败。这些是候选证据，dev.55／插件dev.70固定安装及发布另行记录。完整公开输入矩阵和PC-TX-005任务9.6仍须独立验收，不能由本增量关闭。

签名桌面通过自有loopback监听器、令牌文件和独立数据目录控制；不接管已有用户GUI，不修改全局运行时。技术和原生验证不等于创作接受。
