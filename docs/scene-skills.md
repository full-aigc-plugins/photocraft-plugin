# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `photocraft-restore-old-photo`：老照片修复（划痕、折痕、褪色与局部缺损）
- `photocraft-retouch-portrait`：自然人像精修（皮肤、瑕疵、肤色与光影）
- `photocraft-product-cutout`：电商商品抠图（商品透明底、白底与边缘清理）
- `photocraft-repair-scan`：扫描件清理（扫描图像歪斜、污点与纸张底色）
- `photocraft-social-cover`：社交媒体封面（封面构图、标题与平台裁切）
- `photocraft-batch-image-delivery`：批量图片交付（统一尺寸、色彩与格式）
