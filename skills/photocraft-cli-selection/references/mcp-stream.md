# MCP 流式回复监督

PC-TX-005 / 9.6 的增量候选，目标源 dev.51／插件 dev.66；完整任务继续开放。

公开 cli.py mcp 使用延迟安装和串行转发。首条非法严格JSON、工具结构或已捕获参数在安装／会话前拒绝。各技能均携带独立运行资源，不依赖兄弟技能。有效请求之后才安装和摘要核验固定 craft.5。

客户端字符串／数字ID、初始化、通知、合法工具JSON与图像内容保持原协议。初始化元数据校验版本和结构；工具回复验证结构、内层语义及打开／保存路径。现有额外响应在成功回执和下一编辑之前拒绝。未知或失败结果通过JSON-RPC error.data保留请求、phase、outcome、retryable、recoveryAction、已验证回执及禁止重放标记，并收束本次自有进程。已执行的保存保留，不声称回滚。

测试在真实公开入口与固定原生二进制的保存回复上注入重复键、非有限值、语义错误、错配ID、额外响应及损坏JSON-RPC错误结构；验证下一编辑未发送、原文件摘要不变、保存文件可重新打开。额外响应有实际红灯：未修复时重命名仍被发送。健康路径另验证字符串ID、通知和真实图像预览。

首次调用示例（两个根目录均须为用户授权的实际目录，工程参数使用根目录下相对路径）：

```bash
python3 -I -B "$SKILL_DIR/scripts/cli.py" -- mcp --automation-read-root "$READ_ROOT" --automation-write-root "$WRITE_ROOT"
```
