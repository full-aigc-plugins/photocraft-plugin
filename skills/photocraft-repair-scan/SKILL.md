# 扫描件清理

## 任务起点

先读取素材，确认交付用途、目标尺寸或时长、修改范围与必要格式。能从任务和素材确定的细节直接采用合理默认值；只询问会改变结果的缺失条件。

需要可见编辑器时交给 **photocraft-editor** 技能。独立安装：`npx skills add full-aigc-skills/photocraft-skills --skill photocraft-editor`。当前新增技能为本地候选，发布前使用本地配套插件，不把此安装命令当作已发布证明。

## 执行步骤

1. 保留原始扫描并判断文字是否可读，先纠偏裁边。
2. 依据空白区域估计纸张底色，用温和色阶去灰底，避免吃掉铅笔或浅色印章。
3. 局部修复折痕和灰尘，文字附近限制修复范围。
4. 按原尺寸输出清晰版本；需要 OCR 时交给确有 OCR 能力的工具。

## 工具落地

用 doc_open/doc_new 打开或新建，doc_inspect 查看图层；command_list 查询实际命令，command_run 执行；doc_save 保存 .pcraft，doc_export 导出。

先读取实际工具 schema，再填写参数；对象或文档 ID 使用返回值。查询到的命令必须在当前后端可用。保存前选择新输出路径，保留输入。需要的算法、格式或命令不存在时说明缺口，不能用相近名称冒充。

## 结果检查

- 小字号、细笔画、印章和签名不能被清除。
- 逐页对比内容与页序，不补写猜测文字。
- 交付图像清理结果并区分 OCR 文本是否已实际生成。

对照用户目标检查实际内容，而不只检查进程退出码。局部编辑查看局部细节，版式任务查看整页，时间媒体查看起止与关键段。异常结果先检查当前工程，避免重复执行不可逆操作。

## 交付

返回可编辑工程、实际派生文件和简短说明：做了哪些修改、哪些步骤因当前能力未执行、需要用户判断的内容。只列真实存在且已经检查的文件。若用户随后返工，读取本次源工程并局部修改，保留已接受的内容。
