# 修复流程的定位、取样与结果检查

适用于本技能的去尘、克隆取样、小污点、眼下阴影、定区划痕、补片、油光、杂发和反光点配方。命令与完整参数仍按对应场景手册执行，本页说明如何判断这些命令是否达到本次任务目标。

## 先确认工作层与取样区

1. 查看原图，标出目标损伤与不能改变的邻近轮廓。示例坐标只适用于256×192测试图，不能当作人脸定位结果。
2. 新文件只选中待处理像素层，再复制工作层；已有复杂工程先用inspect读取实际选择和图层ID，明确复制哪个layer。不要直接在调整层上画笔。
3. 取样区要与目标具有可比的纹理、光照和透视，且自身没有损伤。`sampleLayer:"current"`只读取当前工作层；不要误以为它会自动从隐藏原件取样。
4. 克隆的`source`与首个笔画点确定取样偏移，`aligned:true`让后续笔画沿该偏移取样。重开工程或换损伤区后，重新确认源点，不把此前的采样位置当作永久状态。

## 按配方检查实际变化

- 去尘先试一个确定的灰尘点，检查边缘、细线和保护区；近邻修复返回成功不能说明真实纹理已经恢复。
- 克隆和修复画笔用于可比较的已知邻近区域。缺损区域没有可靠内容参考时，只能得到取样补全，不能声称恢复了原始人脸、文字或商标。
- 补片的`mode:"source"`表示修补当前选择，`offset`指向拖至的供体位置；先检查两处内容，再执行，避免从另一个损伤处取样。选区羽化的过渡带允许混合，不要求过渡带逐像素不变。
- 眼下阴影、油光和反光点按低强度试做，保留结构和反光线索。残留部分阴影并非自动失败，过度抹平也不是完成标准。
- 杂发、靠近人物轮廓的划痕要单独检查轮廓侧。扩大笔刷或反复重复同一批次之前，先查看已产生的结果。

不能根据同名方法推断其算法与Photoshop完全一致。官方0.9.0 CLI的规则纹理样例证明了指定参数会改变目标且保留测试保护区，不证明复杂皮肤、织物或银镜反光的真实修复效果。

## 保存并核对原图保留

保存新`.pcraft`，用新进程`photocraft-cli info output.pcraft`读取工作层真实ID，确认其名称、可见性和画布尺寸，再导出PNG查看局部细节。

需要验证原图保留时，在另一个检查副本中执行`layer.setProps`，参数为`{"layer":实际工作层ID,"visible":false}`，然后导出PNG与原始输入对照；参数中的ID必须是运行时取得的整数。检查结束再显式恢复工作层可见性，不将隐藏工作层的检查副本当作最终交付。

有真实未损坏底图时才能计算重建误差。没有底图的真实照片，使用局部前后对照、保护区、边缘和语义检查，不能把测试图的误差改善百分比当作通用画质评分。
