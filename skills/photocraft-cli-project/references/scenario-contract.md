# 场景输入、修改与验收合同

先根据用户已确认需求、素材、当前 `.pcraft` 和目标选择领域技能。使用 `scripts/route.py` 查询已识别意图的唯一归属；自然语言理解由宿主承担，查询结果不等于模型派发验收。显式指定技能时尊重入口范围，已完成前置不重复执行。

| 项目 | 必须明确的内容 |
| :--- | :--- |
| 输入与前置 | 原生工程与清单摘要、登记素材及摘要、运行时与后端、当前目标图层及真实参数；新建必须有合法画幅 |
| 修改与副作用 | 授权对象、属性、选区／蒙版；源工程只读，修改另存；安装、启动会话和编辑分别记录 |
| 保护范围 | 未授权图层、文字、源文件及约定保护区域；没有声明时不声称已核验全部区域 |
| 输出 | `.pcraft`、依赖、预览／约定导出、原生重开、操作回执与损失报告；完整性通过不代替创作接受 |
| 恢复 | 未知结果保留原请求和暂存，不删除登记或换目录重放；核对进程、原文件和已验证检查点后才另行修订 |
| 验收 | 目标实际改变、源与非目标保全、重开后可编辑、所用交换特性及约定输出；未知、失败和未执行分别报告 |
| 不适用 | 无明确目标、无授权覆盖、版本冲突、能力或保护验证不支持时停止对应阶段；不伪造账户、远端任务查询或跨编辑器无损能力 |

文字任务由 `photocraft-cli-text` 检查字体、文本与布局；滤镜任务由 `photocraft-cli-filters` 区分可编辑效果与像素烘焙；原生导出由 `photocraft-cli-export` 记录 PSD 和平面格式损失。各技能按名称交接，缺少时安装 `npx skills add full-aigc-skills/photocraft-skills --skill <skill-name>`。

成功、失败核对与越界拒绝分别见本技能的 `examples/happy-path.md`、`examples/failure-recovery.md` 和 `examples/boundary-refusal.md`。命令参数查询与组合任务均复用本技能公开执行器，不能直接拼接未经核验的 shell。
