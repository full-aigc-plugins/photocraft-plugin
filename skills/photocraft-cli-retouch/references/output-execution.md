# 同目标原生执行登记（技能源dev.30）

公开 workflow.py 在运行时完整性检查后、原生会话之前，在目标父目录保存 `.photocraft-execution-<目标路径摘要>.json`。同一规范化目标只有一个执行所有者；竞争返回 `output_execution_conflict`。登记记录计划、素材、源工程和运行时摘要，不保存原始素材路径或计划正文。

`running`／`reconciling` 不因进程文件锁释放而恢复为可执行。返回 `output_execution_reconciling` 时保全登记、失败暂存与原工程，检查原生进程停止证据并只读重开；不得删除登记后重放，也不能换目标路径绕过原任务核对。尚未提供自动接管、完整幂等、共享预算或任务取消。`finished` 表示工作流退出正常，不等于视觉审核通过。

安装器失败发生在认领之前，可依安装诊断修复；认领之后的异常保守留待核对。已有输出仍返回 `output_exists`，不覆盖用户目录。本实现收录于技能源dev.30；插件的固定安装验收单独记录，不提升完整任务合同。
