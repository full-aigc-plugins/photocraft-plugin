## 1. Definition and audience

PhotoCraft: Layer-preserving image editing and visual design.

For creators who need editable deliverables, repeatable revisions and cross-tool handoff, and engineers building reliable agent workflows. The plugin owns executable workflows and evidence; its independent skill package owns procedural knowledge.

## 3. Brand and copyright boundary

This is a third-party agent integration design, not an upstream endorsement. Names identify compatibility targets; upstream logos and mascots are not copied. Original documentation uses Apache-2.0. Check the licenses of the four applications separately from ArtCraft/Services; the latter informs architecture only and restricted code is not copied. Maintainers check naming and redistribution conditions before distribution.

## 4. Scope and value boundary

Create a poster and cover from product images; after reopening .pcraft, text, product and background remain independently editable; export verified PSD where applicable.

No promise of complete commercial-editor parity, hosted accounts or automatic publication of user media. Support is determined by capability snapshots and actual acceptance evidence.
